What it does

The tool can upload owner-provided videos, update titles and descriptions, set thumbnails, organize playlists, assist with comments, and retrieve channel analytics.

02

Who uses it

It is for the private use of the Shelf to Sense channel owner. It is not offered as a public application or software service.

03

How data is handled

OAuth credentials are stored locally on an owner-controlled computer. Google user data is not sold, shared for advertising, or transferred to data brokers.
